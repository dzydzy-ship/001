# 11 · 表格批量导入 + 批量运算（推荐售价/批量利润）

> 一句话：把商家给的 Excel 商品表（一家一个样）读成"商品草稿"，人工确认后才入库；再一键算出全店推荐售价和批量利润。

## 一、能力清单

| 能力 | 入口 | 说明 |
|---|---|---|
| 表格解析（预览） | 商品管理 → 「批量导入」→ 选择文件 → 开始解析 | 只解析、不入库 |
| 确认入库 | 预览页 → 勾选 → 「确认导入」 | 写商品 + 成本档案 |
| 导出核对 | 预览页 → 「导出 JSON」/「导出 CSV」 | CSV 带 BOM，Excel 直接打开不乱码 |
| 批量推荐售价 | 利润防护 → 「批量运算」 | 全店：成本 + 口径 + 期望毛利率 → 推荐价 |
| 批量利润测算 | 同上（填活动件数/折扣/券） | 按活动算每件利润与利润率 |
| 结构化提取（升级） | 商品管理 → 新增商品 → 预览结构化提取 | 三栏：字段(类别)/识别值/置信度+来源 |

## 二、支持的表格

- 格式：`.xls`（xlrd）、`.xlsx` / `.xlsm`（openpyxl）；单文件 ≤ 30MB。
- 表型：**一维表**（一行一商品）、**多行块表**（多行一商品，价格/货号用合并单元格）。
- 无表头的"首列写货号、右侧写键:值"的表也能兜底解析（价格列会缺失，标为"待补"）。
- 多个 sheet 自动逐个解析，空 sheet / 只有标题的模板 sheet 会跳过并给警告。

## 三、解析算法（7 步，全部通用规则，不含任何商家专用写死）

1. **读**：按后缀选 xlrd / openpyxl，保留单元格内换行（"键:值"常靠换行分隔）。
2. **认表头**：在前 25 行里找"命中列名词最多的标题行"；含 `：` 的行视为数据行排除，至少命中 2 个不同字段。
3. **认列义**：`货号/型号→货号`、`出厂价/成本价/供货价→成本价`、`零售价/售价/标价→售价`、`批发价/渠道价→批发价`、`卖点/特点→卖点`、`产品规格/参数→规格`、`标配/包装清单→包装清单`、`证书/认证→资质`、`单品重量/毛重→重量`、`放产/库存→生产状态`。精确匹配 0.90、包含匹配 0.75。
4. **切块**：多行块表按主键列（优先货号）切；合并单元格用**原始行**判断边界（续行主键为空 → 归上一块）。备注/说明行自动断开、不成块。
5. **抽"键:值"规格**：块内所有文本按行匹配 `键：值`，如 `飞行时间：10分钟左右` → `{飞行时间: 10分钟左右}`；`产品货号/产品名称/产品特点/产品证书/标配` 等自动归位到对应字段。
6. **出草稿**：每块 → 一个 `ProductDraft`（名称/货号/品类/成本/售价/批发价/卖点/规格/包装清单/资质/重量/原始文本/来源 sheet+行/置信度/缺失项/警告）。
7. **确认入库**：按名称去重，写 `products` 表；成本写入成本档案（`product_costs`，备注"表格导入：sheet 名"）。

## 四、接口（给二次开发用）

| 方法 | 路径 | 入参 | 返回 |
|---|---|---|---|
| POST | `/products/import/preview` | multipart `file` | `ImportPreview`（表型/表头行/列映射/商品草稿/警告） |
| POST | `/products/import/confirm` | `{products:[...], create_costs:true}` | `{created, skipped, duplicated, ids}` |
| POST | `/products/batch-calc` | `{margin:20, qty:2, tier_rate:1.0, coupon:0}` | `{rows, summary, policy}` |
| POST | `/products/extract` | `{raw_material:"..."}` | `ExtractPreview`（价格四类/字段来源/置信度/分类/待确认） |

`batch-calc` 每行返回：成本、标价、保本价、推荐售价、建议区间、活动后每件利润/利润率、提示；缺成本的商品标 `missing_cost`。

## 五、实测（飞熊玩具真实 .xls，14.4MB）

- 结果：**45 个商品**（两通道 30 / 三通道 5 / 无刷模型 4 / 涵道飞机 4 / 定制 2），名称 45/45，成本+售价 43/45，规格 45/45。
- 列映射：货号←货号、图片←产品图片、规格←产品规格、包装清单←标配、卖点←卖点、重量←单品重量（含彩盒）、成本价←出厂价、批发价←批发控价、售价←零售控价。
- 规格抽取示例：`飞机尺寸：25.5*23.5*5CM`、`装箱数量：24PCS`、`产品颜色：红色/蓝色`、`客版起订量：10000PCS`。
- 「定制」sheet 没有表头 → 自动按"首列=货号"兜底解析（2 个商品），并提示价格/重量需手动补齐。
- 「2025新品」是空模板 → 跳过并给警告。

## 六、设计约定

- **只预览不落库**：解析永远先出预览；没点"确认导入"不会写库（用户要求"表格信息不导入，只要算法"时，直接用预览结果核对即可）。
- **不写死任何商家**：表头词表是通用的电商字段词；无表头时走兜底规则；换个商家的表也能用。
- **可疑就给提示**：成本>售价、缺售价/成本、无表头、空 sheet、重复货号都会出现在"警告/待补"里。

## 七、已知限制

- 图片只记录图片文件名/链接，不下载（表格里的图片是嵌入对象，需另做导出）。
- 合并单元格跨块（一个合并区域横跨两个商品）无法正确归属，会出现在警告里。
- 无表头的表识别不出价格列（如「定制」sheet），需在预览里手填。
