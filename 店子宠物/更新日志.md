## v1.3 — 2026-10-26　页面细节优化（参数对齐 / 清理冗余文案 / 删除按钮红色）

### 优化

- **批量运算与全店体检的参数行统一格式**：新增 `.param-row` 通用布局（flex 单行不换行 + 等分列，标签不换行并省略溢出，输入框与按钮统一 36px 高、底边对齐），两处卡片的输入框现在**严格在同一条水平线上**；标签精简为「毛利率(%) / 满件数 / 折扣率 / 券额(元)」，「0.8 = 八折」移到输入框占位提示；右侧栏宽度微调（`.chat` 1.25fr→1.1fr）给四个输入框留足横向空间；窄屏（<480px）自动折行不溢出。
- **清理冗余文案**：删除两张卡片标题右侧的说明文字（「同一个活动铺全店，看谁撑得住」「先定价，再测活动」），标题只保留功能名，留白更干净。
- **删除按钮统一改红**：新增 `button.btn.danger` 样式（浅红底 + 红色文字/描边，hover 加深），**商品管理、内容管理、热点列表**的「删除」按钮全部换用危险色，降低误点风险，也与其他按钮形成层级。
- **商品列表操作列不换行**：`#product_list` 操作列 `white-space:nowrap`，让「编辑 / 推荐售价 / 删除」三个按钮排在同一行，不再折成两行。

### 影响文件

- `frontend/index.html`（+15 行 CSS，改 3 处 HTML 结构；无后端 / 数据库改动）

### 验证

- 内联脚本 `node --check` 通过（1 个 script 块、0 报错）；线上页面已返回新结构（`param-row` × 2、`btn small danger` × 3、旧文案已不存在）。
- `.param-row` 采用 flex + `align-items:flex-end` + 标签 `white-space:nowrap`，配合全局 `box-sizing:border-box`，输入框与按钮高度一致、底边对齐；窄屏自动折行不溢出。
- 静态文件实时服务，**无需重启服务**，刷新浏览器即生效。

## v1.2 — 2026-10-26　四项需求 + 页面协调

### 新增

| 模块 | 内容 | 位置 |
|---|---|---|
| 内容生成 | **快手平台**：人群/流量逻辑分析、宣传 Skill（含口播文案与短视频分镜脚本示范） | `config/platforms.yaml`（kuaishou 块）、`config/platform_skill_kuaishou.md` |

| 商品管理 | 预览结果**导出 JSON / CSV**（带 BOM，Excel 直接打开不乱码） | `frontend/index.html`（`exportImportJSON` / `exportImportCSV`） |
| 利润防护 | **批量运算**：全店一次算出保本价 / 推荐售价 / 建议区间 / 活动后利润 / 利润率 | `POST /products/batch-calc`、`frontend/index.html`（批量运算卡片） |
| 结构化提取 | **更聪明的提取预览**：价格分成本/标价/批发/促销四类；每字段带来源、置信度、分类；营销话术不当证据；待确认区 | `app/services/extraction.py`（重写）、`ExtractPreview`、`frontend/index.html`（三栏预览） |
| 测试 | 表格解析 6 条用例（一维表/多行块表+合并单元格/缺价/重复货号/空表/不支持格式）、提取分类用例 | `tests/test_table_parser.py`、`tests/test_extraction_classify.py` |
| 文档 | 表格批量导入与批量运算说明 | `说明文档/11_表格批量导入与批量运算.md` |

### 优化

- **去「AI 味」**：4 份平台 Skill（小红书/B站/抖音/电商详情页）的「内容结构公式」改写为**讲故事骨架 + 反例 + 正例**，并新增「七、别写成这样（AI 味清单）」；生成提示词末尾加**五条硬规则（最高优先级）**：禁冒号词条堆叠 / 只讲 1 个主卖点 / 第一人称+具体场景 / 口语化（禁“本品·该产品·品质卓越·匠心”）/ 自然收尾（禁“快来购买·不容错过”），允许主动说一个真实小缺点。
- **页面协调**：宽表格改为可横向滚动（`.tbl-wrap`）、卡片标题与按钮行统一对齐、预览卡片悬停反馈、勾选框与价格区间标签统一风格。

### 修复

- 表头识别误把「产品货号：FX603」这类**数据行当表头** → 跳过含冒号的行，并要求命中 ≥2 个不同字段；
- 表格底部「备注：…」行被当成商品 → 新增备注前缀识别，备注行结束当前商品块且自身不成块；
- 「定制」sheet 无表头导致逐行成块 → 新增**无表头兜底**（按首列货号切块，并提示手补价格）；
- 测试环境 pydantic 共享默认容器导致用例串值（`'50cm' != '42cm'`）→ 草稿构建时显式初始化容器；
- 「放产」列语义理解错误（原当库存）→ 改存 `specs["生产状态"]`。

### 依赖

`requirements.txt` 新增：`python-multipart>=0.0.9`、`openpyxl>=3.1`、`xlrd>=2.0`（一键启动.bat 自动安装）。

### 实测

- 飞熊玩具真实表格：识别 **45 个商品**（两通道 30 / 三通道 5 / 无刷 4 / 涵道 4 / 定制 2），43 个带成本+售价，45 个带规格；**按用户要求未导入商品库**（仅解析预览）。
- 单元测试：**79 条全部通过**。
- 导入闭环：建商品 → 算推荐售价（49.59 / 保本 39.04）→ 删除，全程 200 且不污染数据。

## v1.1 — 2026-10-25 ~ 10-26　合并版升级（平台 Skill·防幻觉·采集加固·看板分区）

### 新增

- **平台宣传 Skill 体系**：小红书 / B站 / 抖音 / 电商详情页 4 份 Skill 文档 + `app/services/platform_skill.py`（按文件 mtime 热加载，改文档即生效）；`config/platforms.yaml` 增加 `algorithm` / `core_metrics` / `skill` 字段。
- **生成前产品分析**：`build_product_brief()` 把商品资料整理成事实清单（卖点/人群/场景/痛点/证据/限制/资料缺口/各平台切入角度），接口 `POST /content/analyze`，前端显示“产品分析卡”。
- **生成后事实校验**：`fact_check()` 四类规则——数字白名单（价格语境不符=高）、成本泄露=高、无依据宣称=高、商品名未命中=提示；有高危问题时**带着问题清单自动重写一次**。
- 文档：`说明文档/08_平台宣传Skill与事实校验.md`、`说明文档/10_改动成果总结与移植方案.md`。

### 优化

- 内容生成提示词 9 条 + 平台硬性限制（标题字数/标签数量/结构）注入；
- 热点采集加**并发锁**（重复点击返回“上一次采集还在进行中”）、SQLite 开启 WAL + busy_timeout；
- 热点看板拆成**两个子页**：「🔥 热点列表」与「🎯 AI 匹配机会」，避免匹配结果沉底；
- 采集状态显性化：显示“新增 X 条 · 更新 Y 条 · 库中共 N 条”，支持“本次新增”筛选与按更新时间排序。

### 修复

- `loadHotspots()` 漏写 `return` 导致链式调用抛错、界面永远显示“采集失败” → 补 `return api('/hotspots')`；
- `database.py` 使用 `sqlalchemy.event` 与队友测试桩不兼容 → 改为可选导入，兼容假 sqlalchemy；
- 佣金基数口径统一（券后成交额 / 券前成交额），修复“券后利润 −56.26 vs 券前 −58.00”的解释错误（差异恒等于券额×佣金率）。

### 合并

- 以队友“利润防护”完整包为基线：保留其 `pricing.py`（两档佣金基数）、`settings.py`、`costs.py`、推荐售价 UI、`test_commission_base.py`；覆盖我方 15 个文件；前端 6 处手工合并；测试从 68 条增至 79 条全绿。

## v1.0 — 2026-10-23 ~ 10-24　基座功能

### 新增

- **热点采集适配层**：今日头条热榜、B站排行榜 + 8 个分区榜、知乎日报（DailyHot 可选自部署）；单源失败不影响整体。
- **热点归一化**：三级分类（16 板块关键词 → 来源提示 → 综合）、按来源 min-max 热度 30~100、按（来源+标题）去重、保留最近 24 次热度快照与趋势。
- **商品 7 维标签**：品类/功能/场景/人群/痛点/价格带/可蹭热点类型。
- **标签×热点两阶段匹配**：程序筛选候选 + 大模型“AI 挑选”机会（每商品最多 2 个），输出关联理由、创意方向、内容形式、风险与 checklist；已存量组合**原位刷新**不重复建卡；6 路并发加速。
- **推荐售价**：`recommend_price()` + `GET /products/{id}/recommend-price` + 前端弹窗（保本价 / 推荐价 / 建议区间 / 成本拆解）。
- 利润防护（促销测算、毛利红线、全店体检）、内容生成（小红书/抖音/电商）、Agent 对话。

### 修复

- SQLite 存的 naive datetime 与 aware datetime 相减报 500 → `_age_hours()` 统一时区；
- FastAPI 返回 commit 后已过期的 ORM 对象变成 `{}` → `db.refresh()`；
- TF-IDF 对真实热榜分值低导致 0 候选 → 改为排序取候选、交由大模型判定；
- 演示数据与真实数据混排 → 仅当所有真实源失败且库为空时才用 15 条演示热点。
