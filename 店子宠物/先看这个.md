## 起来之后看四处

- 顶部导航顺序：**商品管理 → 利润防护 → 内容生成 → 热点看板 → 设置**。
- **商品管理**：每款商品有「单件利润」列，还能单独设这款的毛利率红线（编辑商品里填）。
- **利润防护**：左边对话框（模型自己选工具，但数字只能由引擎给）、中间账单、右边全店体检。问一句「SR-72 两件八折加 29 元券会亏吗」，账单应出 −56.26（−12.6%）。
- **设置**：大模型只留 DeepSeek / ChatGPT / 通义千问 三家，选一家自动填地址、你只填 Key；下面是可编辑的计价口径（佣金率、基数、运费、红线、默认券额）。

## 我替你修的一个 bug（重要）

设置页原来有第三个选项「含运费成交额」，但引擎只认「券后 / 券前」两档，**选了它就报参数越界**；而且"含运费"本来就已经永远算进佣金基数了。
现在只剩两档：券后（默认，−56.26）/ 券前（−58.00），差额恒为 `券额 × 佣金率`。详见 `说明文档/09_本轮改动清单.md`。

## 你的库里不会自动多出来的东西

新库由 `create_all()` 自动建表；**旧库**如果报 `no such column`，跑这两条：

```sql
ALTER TABLE product_costs ADD COLUMN profit_floor_pct FLOAT;
ALTER TABLE promo_configs ADD COLUMN default_coupon FLOAT;
```

另外：包里**没有** `data/app.db`（你原来那个 540KB 的本机库我没带，免得覆盖别人的数据）。

## 两件要你确认的事

1. **合成一个入口还是两个**：现在是一个页面五个标签（已有你要的热点看板），建议就这样，评委一眼能看出是一个作品。
2. **你的文案里要不要引用利润数字**：要引用的话，接口给你三个字段——成本、标价、当前利润率。
