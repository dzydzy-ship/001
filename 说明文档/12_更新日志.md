## v1.4 — 2026-10-28　启动器重写：换电脑能用 / 局域网可访问

### 问题

旧 `一键启动.bat` 把地址写死成 `http://127.0.0.1:8000`：`127.0.0.1` 是「本机回环地址」，别的电脑打开只会指向**它自己**，所以换电脑、手机、投影仪访问全部失败。
除地址外，换台机器还会依次踩到这些坑：

1. 项目里带的 `.venv` 是**别人机器上**建的，里面的 Python 绝对路径本机不存在，`python.exe` 直接起不来；
2. `where python` 会命中 Microsoft Store 的**占位空壳**（`WindowsApps\python.exe`，一执行就跳商店），误判成「已装 Python」；
3. 8000 端口被别的程序占用时没有任何兜底，服务静默启动失败；
4. Windows 防火墙默认拦截外部机器的入站连接，同一 Wi-Fi 下的手机 / 同事电脑打不开；
5. pip 只试官方源，国内网络下装依赖经常卡死或超时；
6. 固定 `Start-Sleep 5` 后开浏览器，首次启动要建库、采热点，经常是「页面打开是空白 / 无法访问」的竞态；
7. 出问题没有任何提示，只能看着黑框一闪而过。

### 改动

- **启动逻辑整体搬到 `scripts\launcher.ps1`**（PowerShell），`.bat` 只做纯 ASCII 引导（避开 cmd 按 GBK 解码中文脚本的乱码问题），双击后自动调用。
- **自动探测 Python**（不再信任 `where python`）：`py -3` → `py -0p` 列出的路径 → `PATH` 里的 `python` / `python3`（剔除 `WindowsApps` 空壳）→ 注册表 `Python\PythonCore` → `%LOCALAPPDATA%` / `%ProgramFiles%` 下常见目录；逐个真跑 `import sys` 校验，要求 ≥ 3.10，取最高版本。
- **`.venv` 跨机失效自动重建**：要求 `.venv\Scripts\python.exe` 里 `sys.prefix` 真的指向当前 `.venv`，不对就改名成 `.venv.broken-<时间戳>` 留档并重建（原来那份不会丢）。
- **依赖只在需要时装**：按 `requirements.txt` 内容哈希记一个 marker 文件，marker 命中且 10 个关键模块都能 import 就跳过；需要装时先试 PyPI 官方，失败依次切清华 TUNA / 阿里云 / 腾讯云镜像。
- **端口自动顺延**：首选端口被占就从 +1 试到 +30，找到空闲的再启动；同时先扫一遍 8000~8020，**发现同一套程序已经在跑就只打开浏览器**，不会起第二份进程去抢同一个 SQLite 数据库。
- **默认监听 `0.0.0.0`**（局域网可访问），启动成功后在窗口里同时打印「本机地址」和「局域网地址」，手机 / 同事电脑照着输即可；只想本机用就加 `-Local`，或在 `.env` 里写 `APP_HOST=127.0.0.1`。
- **用轮询 `/health` 代替固定等待**：最多等 90 秒，服务真能回 `{"status":"ok"}` 才开浏览器；健康检查**显式禁用系统代理**，避免开着 VPN / 代理的机器上把本机请求转发出去。
- 新增 `允许局域网访问.bat` + `scripts\allow_firewall.ps1`：一键添加 Windows 防火墙入站规则（TCP 8000-8020，仅本地子网，涵盖公用网络配置），非管理员时自动弹 UAC 提权，可用 `-Remove` 撤销；结果写 `logs\防火墙结果.txt`。
- 新增 `诊断工具.bat`（`scripts\launcher.ps1 -Diagnose`）：逐项检查系统 / 路径风险（OneDrive、中文路径、超长路径）/ Python / `.venv` / 依赖 / 端口占用进程 / 局域网 IP / 防火墙 / `import app.main` 自检 / 上次启动记录，屏幕上打印并同时写 `logs\诊断报告.txt`，方便远程排查。
- 每次启动写 `logs\最近一次启动.txt`（时间、目录、Python 版本、venv、监听地址、本机与局域网 URL）。
- 统一退出码：`0` 成功、`2` 找不到 Python、`3` 环境或依赖安装失败、`4` 服务启动失败、`9` 启动器自身异常，便于脚本化排查。
- `scripts\serve_local.py` 同步改为读 `APP_HOST`（默认 `0.0.0.0`）/ `APP_PORT`（默认 8010），并打印局域网地址。
- `.env.example` 增加 `APP_HOST` / `APP_PORT` 说明，LLM 默认值对齐 DeepSeek（`https://api.deepseek.com/v1` + `deepseek-chat`）。
- 文档：`README.md`「快速开始」改写为「装 Python → 解压 → 双击」+ 常见问题表 + 局域网排障步骤；`先看这个.md` 同步；新增 `说明文档/13_启动器与局域网访问.md`（原理、新旧对照、退出码、排障 9 步、安全提醒）。

### 影响文件

- 新增：`scripts\launcher.ps1`、`scripts\allow_firewall.ps1`、`允许局域网访问.bat`、`诊断工具.bat`、`说明文档\13_启动器与局域网访问.md`
